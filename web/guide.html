    폴더 하나 만들고(예: /home/user/mail), 받은 txt 9개를 전부 VS Code 왼쪽 탐색기에 드래그 & 드롭

  3. 복원 — Claude에게 시키면 됨

    스크립트가 하는 일: DB 조각 합치기 → 압축 해제 → 검색 인덱스 재생성(1~2분) → txt들을 원래 이름(.py/.md/.json)으로 되돌리기 → 검증

  4. 폴더 열기 ← 가장 중요

    VS Code 메뉴 File → Open Folder → /home/user/mail/she-law-db

    이 단계를 건너뛰면 Claude가 DB도 답변 규칙도 인식하지 못하고 그냥 일반 답변을 한다. "폴더를 연다" = "이 DB를 쓰겠다"는 스위치.
  5. 동작 확인

    Claude Code 패널에 그냥 질문 (슬래시 명령 불필요):

    유해화학물질 영업허가 받으려면 뭐가 필요해?

    정상이면 [✅ DB 근거] 배지 + [화학물질관리법 제28조] 인용 + 조문 원문이 함께 나온다.

    제대로 됐는지 확인하는 법: DB에 없는 걸 일부러 물어본다 (예: "식품위생법 영업신고 절차"). [❌ 근거 없음]이 뜨면 정상. 그럴듯하게 답해버리면 4번을 안 한 것.
  6. 동료에게 배포 (선택)

    복원한 she-law-db 폴더를 사내 깃 저장소에 올리면, 동료는 "이 저장소 클론해줘" → 폴더 변경 → 질문 3단계로 사용. (DB 35MB라 LFS 지원 여부 확인)

검색 도구 사용법

Claude가 알아서 호출하지만, 터미널에서 직접 확인할 수도 있다
# 조문 검색 (동의어 자동 확장)
python search_law.py find "유해화학물질 영업허가"
python search_law.py find "독성가스" --tier 법률

# 조문 전문 — 검색 결과의 article_id로
python search_law.py article 36

# 물질 규제 등재 조회 (CAS 또는 물질명)
python search_law.py substance 7664-39-3

# 법령 목록 / 특정 법령의 조문 목록
python search_law.py laws
python search_law.py laws 화학물질관리법

출력은 JSON. Claude는 이 결과의 조문만 근거로 인용하고, 결과가 없으면 "확인 불가"로 답한다.

거짓 답변을 막는 장치

"DB에서 찾은 답"과 "AI가 아는 척한 답"을 눈으로 구분하게 만든 규칙
장치내용
출처 배지답변 첫 줄에 [✅ DB 근거] / [⚠ 부분 근거] / [❌ 근거 없음]
인용 강제모든 사실 문장에 [화관법 제28조] 형식 근거. 검색 결과에 실제로 있던 조문만 인용 가능
조문 원문 동봉조 번호만 던지지 않고 원문 발췌를 함께 — 따로 찾아볼 필요 없게
없으면 거부못 찾으면 "DB에서 근거를 찾지 못했습니다"
물질은 대조로 확정규제 대상 여부는 추론 금지 — 별표 원문 대조 결과만 사용
실제 사례: HfCl4(사염화하프늄) 취급시설을 물었더니 — 절차 조문(화관법 제23·24조)은 원문까지 제시하고, 정작 "HfCl4가 유해화학물질인지"는 별표에 없어서 [⚠ 부분 근거]로 "MSDS/NCIS에서 별도 확인 필요"라고 답함. 아는 것과 모르는 것을 갈라주는 게 이 시스템의 값어치.

법 개정 반영 · 재전송

인터넷 되는 집 PC에서 갱신 → 다시 메일로

① 집 PC에서 갱신 (주 1회 권장)

# safety_law 폴더에서 순서대로
python collector.py        # 법령·고시 (개정분만 다운로드)
python annex_collector.py  # 별표 (신규분만)
python kosha_collector.py  # KOSHA 지침 (신규분만)
python importer.py         # laws.db 재생성

개정이 없으면 몇 초 만에 끝난다. 법령마다 버전 번호가 있어 바뀐 것만 다시 받는다.

② 메일 전송 패키지 다시 만들기

갱신된 data/laws.db를 dist/she-law-db/data/에 복사한 뒤, 메일용 txt를 다시 생성하면 된다. (생성 절차는 이 작업 이력 참고)

법령을 더 넣으려면

laws.json에 법령명(국가법령정보센터 공식 명칭)을 추가하고 collector → importer 재실행. 고시는 admrul 배열에 추가.

주의: kosha_config.json(공공데이터포털 API 키)은 절대 전송 패키지에 넣지 말 것. 사내에서는 수집을 하지 않으므로 필요 없다.
